# 🖌️ Pals Paint Website - `pals-web`

Welcome to the official codebase of the **Pals Paint** website!

This is the modern, responsive promotional website for **Pals Paint**, a brand committed to delivering high-quality wall paints.  
It currently serves as a branding and information platform, and is planned to evolve into a full-fledged eCommerce website.

🌐 **Live Site**: [www.palspaint.com](https://palspaint.netlify.app/)

---

## 🚀 Project Overview

- **Project Name**: pals-web
- **Purpose**: Marketing and branding for Pals Paint products
- **Future Scope**: Full eCommerce functionality with online ordering, user accounts, payment gateway, and more

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Framework**: Angular 16
- **Hosting**: Netlify

---

## 📦 Features

- Clean and modern UI
- Mobile-responsive design
- Product showcase
- SEO-friendly structure
- Future support for eCommerce
